### Decisions taken from the bundled Next.js 16.4 documentation

* `cacheComponents` is **disabled**. With it enabled every session read must sit behind
  a `<Suspense>` boundary or the build fails. SUNLEON AI is predominantly an
  authenticated, per-tenant application, so the classic dynamic rendering model is
  simpler and less error-prone. Marketing pages are still statically rendered.
* `partialPrefetching` was removed because it requires `cacheComponents`.
* `agentRules: false` stops `next dev` from generating `AGENTS.md`/`CLAUDE.md` files.
* `prisma init` installs AI-agent skill folders (`.agents/`, `.claude/`, `.windsurf/`);
  they were removed from the repository and are git-ignored.
